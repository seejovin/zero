# zerø

Android non-custodial wallet for sending, receiving and holding supported mainnet assets.

The current source candidate is version 0.12.0. It includes an experimental local zero-knowledge private-transfer engine and gas sponsorship service. Android compilation, signing, device qualification and production service deployment are tracked separately. Private gas transfers remain disabled until the deployment and device qualifications are complete.

This repository will contain the complete buildable wallet source and a GitHub Actions Android build. No wallet recovery phrases, user vaults, app signing keys or operator treasury keys belong in this repository.
